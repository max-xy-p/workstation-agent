# 项目文档

首次使用从 [README](../README.md) 开始，再按需要阅读对应功能。每项配置、接口和操作规则只在其所属文档中维护。

除数据库部署与前端说明中的特别标注外，下列文档的 Python 命令均在 `backend/` 执行，
并沿用快速开始中指向仓库根目录的工作区配置；工具参数中的文件路径相对于该工作区。
