## 文档维护规则

- `README.md` 是简洁的用户入口，不承载完整设计细节。
- `architecture.md` 记录长期稳定的架构原则和目标，不作为任务清单。
- `modules.md` 是当前实现状态的事实来源；代码变化后需要同步更新。
- `agent.md` 描述运行时行为，任何状态或事件语义变化都要同步修改。
- 接口和配置的细节应靠近代码，并通过 docstring 和测试保持准确。
