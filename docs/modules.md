# 功能状态

本表只记录已实现能力与后续范围，使用方法见各功能文档。
前后端已分别归入 `frontend/` 与 `backend/`，各自维护依赖、测试和构建配置；Agent 的内部模块边界保持原设计。

| 模块 | 已实现 | 后续范围 |
| --- | --- | --- |
| Agent 与模型 | 官方 create_agent / LangGraph、OpenAI 兼容工具调用、次数限制、审批恢复、超时与取消 | 外部模型与真实任务效果验收 |
| 接口与会话 | CLI、MCP、Agent HTTP；会话与消息 CRUD；运行历史管理；外部 MCP HTTP/stdio 连接、工具白名单、调用前审批和标准结果适配 | 事件订阅、工作台新版 MCP/SDK 的业务适配 |
| 前端 | React 工作台：会话与消息管理、任务控制、历史运行选择/分页/删除、刷新后加载轨迹、审批恢复；响应式布局与显式演示模式 | 任务项验收入口、逐 Token 流、模型与文件操作的配套后端能力 |
| 工具与安全 | 工作区目录和文本读取、分段读取；严格参数、分级权限、参数绑定审批、错误脱敏 | 通用文件写入、更多敏感内容识别 |
| Context | 完整请求预算、压缩、有界刷新、来源记录、任务状态与用户验收 | 实际用量偏差与摘要质量校准 |
| Memory | PostgreSQL 文本 CRUD、范围隔离、过期、遗忘保护、BM25 召回、可选 LangMem 提取 | 同义召回、已验证执行经验的自动提取 |
| RAG | Markdown/纯文本、完整外部正文摄取 API、明确的标题/格式/来源版本、分块、混合检索、引用与整篇索引替换 | 工作台笔记自动获取/同步、PDF/Word/网页、大规模索引、真实语料评估 |
| 存储 | PostgreSQL 业务表、官方检查点、版本化迁移、自动保存 Run/Step 与任务进度，按身份隔离 | 旧数据自动导入与备份管理 |

普通 CLI 任务默认不保存会话；`--session` 可单次启用，HTTP 始终启用。
运行历史保存到数据库，进程内缓存上限 128 条；重启不删除轨迹，也不会自动续跑中断任务。自动记忆提取和额外模型出站默认关闭。
离线测试验证协议与业务边界，不代表外部模型效果已验收。
